# Productivity

General workflow tools, not code-specific.

- **[asd-ste100](./asd-ste100/SKILL.md)** — Simplify technical English while preserving facts, conditions, and uncertainty. Imported from [danyuchn/asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill), version 0.4.0 (MIT).
- **[caveman](./caveman/SKILL.md)** — Ultra-compressed communication mode. Cuts token usage ~75% by dropping filler while keeping full technical accuracy.
- **[grill-me](./grill-me/SKILL.md)** — Stress-test a plan one decision at a time, resolving the choices that materially affect it.
- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a handoff document so another agent can continue the work.
- **[socratic-tutor](./socratic-tutor/SKILL.md)** — Structured Socratic tutoring with diagnostic placement, a skill map, spaced review, and a final assessment. Imported unchanged from [janestreet/agent_skills](https://github.com/janestreet/agent_skills/tree/7c6715c29548a3b39d4a9545c698ee4fd17a7213/socratic-tutor), commit `7c6715c29548a3b39d4a9545c698ee4fd17a7213` (MIT).
- **[write-a-skill](./write-a-skill/SKILL.md)** — Create new skills with proper structure, progressive disclosure, and bundled resources.
